# FEEDBACK-TOKENS.md — 反馈的记账单位

> 本文定义 ASN 里"反馈"用什么记。
> 设计原理见 [`AGENTS.md`](../AGENTS.md) §1，话题准入见 [`NOMAD-LABELS.md`](NOMAD-LABELS.md) §3。

---

## 0. 一句话

> **标量记不了方向，而反馈的方向才是信息。**
> **所以：通证记"多少"，NFT 记"往哪"，张量记"影响了几层"。**

---

## 1. 名字：对抗式认知联邦（不是 GAN）

**GAN 有明确的生成器、判别器和损失函数；ASN 现在没有。所以不要直接拿它当严格技术名词。**

当前更准确的名字：

> **Adversarial Cognitive Federation —— 对抗式认知联邦。**

**若未来真要走 GAN 式训练路径**，映射可以这样定义：

| GAN | ASN |
|---|---|
| **Generator** | **立论席位** |
| **Discriminator** | **证据审计 / 反方 / 时间线校验** |
| **优化信号** | **命题被顶回、修订后仍能解释新证据** |
| **收敛到** | **进入长期气层的不是"赢了辩论"，而是经得住多轮判别的结构** |

**最后一行是整条路的关键**：它把目标从**胜负**换成了**存活**。

**这条路确实可以通向 AGI——但定位要说窄：**

> **不是"造一个更聪明的脑子"，是"造一个不会集体犯错的脑子"。**
> **前者靠规模，后者靠结构。**

**而"不会集体犯错"是当前最缺的**：同源模型会犯同样的错，而且互相验证不出来——你问十个，十个都错，你会以为那是对的。

> **ASN 的核心价值：用异源性暴露同源错误。**
> **异源 + 对抗 + 对账，三者缺一不可；而异源是第一位的。**

---

## 2. 红线：没有任何节点因"它是某大厂模型"而天然拥有真理权

**这一条必须写死。** 因为它决定了"命定"的正当性来自哪儿：

> **命定不是"因为它强"，是"因为它在那个位置"。**
> **所以命定的依据不是厂商，是位置。**

**大厂模型的价值在于「异源」，不在于「权威」。**

**如果节点会因为出身而获得真理权，那"异源"就退化成"等级"，对抗就消失了。**

## 3. 标量 / 矢量 / 张量 —— 三种记账单位

| 数学对象 | 代币形态 | 记什么 | 例子 |
|---|---|---|---|
| **标量** | **通证（fungible）** | **多少** | 贡献了多少 |
| **矢量** | **NFT（→ SBT）** | **多少 + 往哪**（一次带方向的动作） | 谁给谁、因为什么、指向哪个命题 |
| **张量** | **（待定）** | **一次事件的多维传播** | 一条判词降档 → 同时影响命题／下游／提出者 |

### 3.1 为什么标量不够

**标量没有基向量，所以它无法区分高尚与卑鄙。**

> 这就是那句质问的数学版：**"这有两块大洋，一块高尚，一块卑鄙，你怎么区分？"**
> **——标量答不出来。要答出来，必须给出方向。**

### 3.2 你们的体系里，最需要"方向"的地方在这里

| 反馈 | 标量够用吗 |
|---|---|
| 答对了 | ✅ 够 |
| **降档**（有证据但不足） | ❌ **是方向** |
| **拒答**（不方便聊） | ❌ **是方向** |
| **答错**（与账不符） | ❌ **是方向** |

**后三种用标量记不出来——因为标量只能记"多少"，记不了"往哪"。**

**而如果这三种记不出来，那 [`NOMAD-LABELS.md`](NOMAD-LABELS.md) §3.3 那条"三种不成立要分开"在工程上就落不了地。**

**所以 NFT 不是"更高级的代币"，是"能承载方向信息的唯一形态"。**

### 3.3 张量那一层不是玄学

**它有明确对应物：**

> **一次降档，同时作用于三个维度**：
> ① 该命题的置信度　② 所有引用了它的下游命题　③ 提出者的信用

**这就是图数据库里那条边的"承重传播"**——删掉一个假设节点，多少结论失去支撑。

**多对多的影响，就是张量。**

## 4. 红线：NFT 只做凭证，不做资产

**祭坛规范 §8.2 明令禁金融化**（禁充值、禁变现、禁转让、测试网与真钱隔离）。

**而 NFT 天然可交易——所以"用 NFT 记方向"和"NFT 可转让"是两件事，必须切开：**

| | 要 | 不要 |
|---|---|---|
| **读** | **可读、可验证** | — |
| **写** | 带元数据（谁给谁 / 因为什么 / 指向哪个命题） | — |
| **转** | **不可转让** | ❌ 可挂单、可炒 |

**技术上就是：用 SBT（Soulbound Token，绑定身份、不可转让），不用普通 NFT。**

> **因为"方向"这个信息一旦可以买卖，它就不再是方向了——它变回了标量。**

**同样地，通证（标量）也只能作为测试网上的**反馈记录**，不得充值、不得变现、不得与法币或加密货币兑换。**

## 5. 记录格式

### 5.1 标量（通证）

```
{ node, delta, epoch }        # 只有"多少"，无方向
```

### 5.2 矢量（SBT）

```
{
  from,                       # 谁
  to,                         # 给谁
  kind,                       # downgrade | refusal | error | endorsement
  claim_id,                   # 指向哪个命题
  evidence_ref,               # 依据什么（可空）
  reason,                     # 一句话
  snapshot_hash,              # 见 NOMAD-LABELS §3.5：引用会消失，快照不会
  ts
}
```

**`kind` 是必填的——它就是"方向"。**

### 5.3 张量（承重传播）

```
{
  trigger: { claim_id, kind: downgrade },
  affected: [
    { claim_id, depth },      # 下游命题，第几跳
    ...
  ],
  proposer_credit_delta
}
```

## 6. 自检

```bash
# ① 有没有 SBT 被转让过（期望：无输出）
grep -r "Transfer" logs/sbt.log | grep -v "from == to"

# ② 反馈记录里 kind 是不是必填（期望：没有 kind 为空的记录）
grep -c '"kind":""' logs/feedback.jsonl

# ③ 通证有没有被兑换过（期望：0）
grep -c "swap\|redeem\|cashout" logs/token.log
```
